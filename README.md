## Эксперимент №1. Baseline

В качестве базового решения используется гибридный TF-IDF-поиск по заголовкам и текстам статей.

HTML-разметка статей очищается, после чего тексты приводятся к нижнему регистру, символ `ё` заменяется на `е`, а пунктуация и лишние пробелы удаляются. Для представления текстов используются два TF-IDF-векторизатора:

* word TF-IDF с униграммами и биграммами;
* character TF-IDF с символьными n-граммами длиной от 3 до 5 символов.

Сходство запроса со статьёй рассчитывается отдельно для заголовка и основного текста. Итоговая оценка представляет собой взвешенную сумму четырёх значений:

* word TF-IDF по заголовку;
* word TF-IDF по тексту;
* character TF-IDF по заголовку;
* character TF-IDF по тексту.

Веса подбираются по `MAP@10` на обучающей части `calibration.f`. Для локальной оценки размеченные запросы делятся на train и validation в соотношении 75/25. После оценки финальные веса подбираются на всём `calibration.f` и используются для ранжирования статей из `test.f`.

Для каждого тестового запроса сохраняются 10 наиболее релевантных `article_id` в файл `answer.csv`.

Локальный результат baseline:

```text
MAP@10 на validation: 0.174008
```

## Эксперимент №2. Перенос релевантности от похожих запросов

Гибридное решение объединяет прямое TF-IDF-сходство запроса со статьями и перенос релевантности от похожих размеченных запросов.

Локальная оценка проводилась на пяти групповых разбиениях `calibration.f`. Одинаковые нормализованные запросы не могли одновременно находиться в обучающей и валидационной частях.

* TF-IDF baseline: `MAP@10 = 0.1777 ± 0.0189`
* Hybrid retrieval: `MAP@10 = 0.5286 ± 0.0170`

Такой резкий прирост метрики кажется немного странным, но повторив эксперимент на пяти разных значений `random_state`: `13`, `21`, `42`, `77` и `101`, я решила, что метрике можно доверять.

На всех разбиениях гибридный подход показал близкие результаты:

```text
0.5146
0.5159
0.5187
0.5515
0.5421
```

Небольшой разброс между разбиениями показывает, что прирост качества не связан с удачно выбранным seed или случайным составом validation-выборки.

Таким образом, значение `MAP@10 ≈ 0.53` можно считать устойчивой локальной оценкой качества гибридного решения.

## Эксперимент №3. Накопление вклада похожих запросов

В прошлом эксперименте для каждой статьи учитывался только максимальный голос одного наиболее похожего размеченного запроса. В новом эксперименте оценки всех ближайших запросов, содержащих статью в `ground_truth`, суммируются.

Плюс подбирались количество соседей, способ агрегации, степень усиления сходства и вес смешивания с прямым поиском по статьям.

Локальная оценка на пяти групповых разбиениях:

* TF-IDF baseline: `MAP@10 = 0.1777 ± 0.0189`
* Similar-query label propagation: `MAP@10 = 0.5286 ± 0.0170`
* Aggregated neighbor voting: `MAP@10 = 0.6231 ± 0.0295`

На всех пяти разбиениях лучшим способом агрегации оказался `sum`, что логично и подтверждает гипотезу: если одна статья встречается у нескольких похожих запросов, накопление этих голосов является более надёжным сигналом релевантности, чем использование только одного ближайшего соседа.

Финальная конфигурация использует 30 соседей, суммирование, квадрат сходства и равное смешивание оценок поиска по статьям и похожим запросам.


## Эксперимент №4. Распространение релевантности по связям между статьями

В `ground_truth` одного запроса часто встречается несколько связанных статей. Чтобы использовать этот сигнал, был построен граф их совместной встречаемости.

После получения базовых оценок часть веса от наиболее вероятных статей переносится на документы, которые часто встречаются вместе с ними.

Локальная оценка на пяти групповых разбиениях:

* Aggregated neighbor voting: `MAP@10 = 0.6231 ± 0.0295`;
* Article co-occurrence propagation: `MAP@10 = 0.6261 ± 0.0271`.

Прирост небольшой, но стабильный: связи между статьями дают дополнительный сигнал, который не полностью учитывается текстовым поиском и похожими запросами.

(Все наиболее оптимальные параметры из прошлых экспериментов захардкожены, чтобы заново не перебирать)


## Эксперимент №5. Обучаемый reranker на Logistic Regression

После анализа качества базового гибридного поиска выяснилось, что около 97% релевантных статей уже попадают в top-50 кандидатов. Основная проблема заключалась не в поиске документов, а в их порядке внутри выдачи.

Для улучшения ранжирования был добавлен второй этап — обучаемый reranker на `LogisticRegression`. Для каждого запроса формировался пул кандидатов из top-50 статей по TF-IDF и top-50 статей по похожим размеченным запросам. Для каждой пары «запрос — статья» рассчитывались признаки:

* TF-IDF-сходство с заголовком и текстом статьи;
* накопительный голос похожих запросов;
* максимальное и среднее сходство соседей;
* количество соседей, проголосовавших за статью;
* позиции статьи в отдельных ранжированиях;
* Reciprocal Rank Fusion score;
* частота статьи в `ground_truth`.

В качестве отрицательных примеров использовались нерелевантные статьи из пула кандидатов, то есть сложные отрицательные примеры. Признаки для обучающей выборки строились в out-of-fold режиме, чтобы запрос не мог использовать собственную разметку через поиск похожих запросов.

Средний результат по пяти валидационным разбиениям:

| Метод                        | MAP@10 | Recall@10 | Recall@20 |
| ---------------------------- | -----: | --------: | --------: |
| Гибридный baseline           | 0.6274 |    0.8739 |    0.9263 |
| Logistic Regression reranker | 0.6411 |    0.9040 |    0.9440 |


## Эксперимент № 6. Смешивание reranker и hybrid-score

После обучения `LogisticRegression` reranker был проведён эксперимент со смешиванием его вероятности с исходным hybrid-score. Итоговый score рассчитывался по формуле:

```python
final_score = alpha * reranker_probability + (1 - alpha) * normalized_hybrid_score
```

Проверялись значения `alpha = 0.25, 0.5, 0.75, 1.0`. Лучший результат показал `alpha = 0.75`.

| Метод               | MAP@10 | Recall@10 | Recall@20 |
| ------------------- | -----: | --------: | --------: |
| Hybrid baseline     | 0.6274 |    0.8739 |    0.9263 |
| Blend, alpha = 0.75 | 0.6523 |    0.9085 |    0.9506 |
